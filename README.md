# AI Career Coach

AI Career Coach is an AI-powered platform designed to assist users in navigating their career journeys by providing personalized insights, interview preparation, resume building, and more. This app integrates **Next.js**, **Shadcn UI**, and **Gemini AI** for various AI-powered features like **industry insights**, **mock interview generation**, and **resume building**.

## Intro

AI Career Coach is a full-stack web application designed to enhance career development by leveraging AI-powered tools. It includes user authentication, personalized industry insights, mock interview simulations, and a dynamic resume builder, all driven by cutting-edge AI models.

## Setup

Follow the steps below to set up the project on your local machine:

### Setup Next JS and Shadcn UI

1. Clone the repository.
2. Install dependencies.
3. Set up **Next.js** and **Shadcn UI**.

### Backend Setup

1. Configure the backend with the required environment variables.
2. Set up the **Gemini AI API** for generating industry insights and mock interview questions.

### Inngest Setup

1. Set up **Inngest** for handling cron jobs related to weekly insights generation.

## Features

### User Authentication

* Custom login/sign-up page for users.

### Landing Page

* A welcoming landing page for introduction and navigation.

### Onboarding Page

* Collects user data and preferences through a form.

### AI Career Insights

* Provides career-related insights using **Gemini AI** based on the user’s preferences.

### Interview Preparation

* Generates mock interview questions with AI.
* **Interview Performance Stats** page to show results.

### Resume Builder

* **AI Resume Builder**: Generates resumes based on user data.
* **Markdown Resume**: Converts resumes into markdown format and allows downloading as PDFs.

### Cover Letter Generator

* Generates personalized cover letters based on job descriptions and user data.

## Database Design

* Uses a relational database to store user profiles, resume data, and preferences.

## Deployment

* Deployed on **Vercel**.

  * Link to the deployed app: [https://ai-career-coach-beryl-one.vercel.app](https://ai-career-coach-beryl-one.vercel.app)

## Technologies Used

* **Frontend**: Next.js, Shadcn UI, React
* **Backend**: Node.js, Gemini AI API, Inngest for serverless functions
* **Database**: SQL (PostgreSQL or MySQL)
* **Deployment**: Vercel
